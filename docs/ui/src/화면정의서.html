설계 원칙

  • 앱을 보지 않아도 된다. 탑승 후 할 일은 없다. 앱 화면은 설정할 때만 연다.
  • 필요할 때만, 방해하지 않게. 큐는 가장자리에만, 터치는 아래 앱으로. Tier 1·2는 알림 문구만 바뀐다.
  • 끊기면 끈다. 연결이 불확실하면 큐를 남기지 않는다 (NFR-01).
  • 조작은 가장 가까운 곳에서. 알림 버튼 · 빠른 설정 타일 → 앱 홈 순.

APP-05 홈에서 언제든 APP-04(프로필), APP-06(설정), APP-07(진단)으로 이동. 앱을 닫아도 서비스는 계속 동작.

알림 원칙

  • 채널 중요도 낮음: 헤드업·소리·진동 없음. 영상 시청을 끊지 않는다.

  • 알림은 사용자가 지울 수 없다(포그라운드 서비스). 하차(브리지 사라짐) 시 자동으로 내려간다.

화면 꺼짐 · 잠금

화면이 꺼지거나 잠기면 오버레이를 숨기고 SCR{on:false, att:false}. 잠금 해제 시 att:true로 다시 보내고 Tier 3이 켜져 있으면 큐를 다시 그린다.
